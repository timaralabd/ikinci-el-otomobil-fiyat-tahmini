# İkinci El Otomobil Özelliklerinden Fiyat Tahmini

Bu proje, ikinci el otomobillerin özelliklerini kullanarak araç fiyatlarını tahmin etmeyi amaçlamaktadır.

## Proje Ekibi
Proje 3 kişilik bir ekip tarafından geliştirilmektedir.

## Projenin Amacı
Araçların marka, model, üretim yılı, kilometre, yakıt türü, vites türü ve diğer özelliklerini kullanarak ikinci el satış fiyatını tahmin eden bir model geliştirmektir.
